# PhotoDrop Frontend

React client for PhotoDrop, built with Vite, Tailwind CSS, and React Router.

## Development

```bash
npm install
npm run dev
```

The client will start at `http://localhost:5173` with an automatic proxy forwarding `/api` and `/media` requests to the Django backend on port 8000.

## Production Build

```bash
npm run build
```

The production output is placed into `dist/`.
